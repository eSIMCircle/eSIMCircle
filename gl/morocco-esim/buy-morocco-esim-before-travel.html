FAQ

Common questions

When should I install the eSIM?

Install before departure while you have stable Wi-Fi, then activate mobile data when you arrive in Morocco.

Can I keep my home SIM active?

Yes. Many travelers keep their home SIM for calls or SMS and use the eSIM line for mobile data.

Which plan should I choose?

Choose small fixed data for light trips, larger fixed data for longer stays, or daily plans for consistent high usage.
