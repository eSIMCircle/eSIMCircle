eSIM APN settings for Italy: a symptom-by-symptom guide

An Italian trip can include airports, fast trains and hill towns in one day. If your travel eSIM stops loading data along the way, match what you see to the table below before opening the APN screen.

Published April 11, 2026 · Updated May 4, 2026 · 3 min read

Start with the symptom

What the phone showsMost likely causeFirst thing to try
No signal bars on the Italy lineLine turned off or network not foundTurn the line on, then restart
Signal bars, but "No Internet"Wrong data line or roaming offSelect the eSIM for data, turn roaming on for it
Signal and data work, then stopWeak area or train tunnelWait for a stronger area, then toggle airplane mode
Data works only on Wi-FiHome SIM still set for dataSwitch mobile data to the Italy eSIM
Everything above checked, still no dataAPN missing or editedCompare the APN with your instructions

Most cases end in the first three rows. The APN is the last stop, not the first.

What the APN actually does

The APN is a short setting that tells the phone which gateway to use for mobile data. Travel eSIMs usually fill it in for you. If it is blank or was edited, data will not flow even with full signal.

Where to find it

On iPhone: Settings > Mobile Data > select the Italy line > Mobile Data Network.

On Android: Settings > Network & internet (or Connections) > SIMs > select the Italy line > Access Point Names. The exact menu wording varies between Samsung, Pixel and other brands.

What to do there

If a value is already present, leave it. If the field is blank, enter only the exact value from your eSIMCircle instructions or from support. Do not copy one from an Italian carrier's website; it belongs to a different service.

NoteOn Android, "Reset to default" in the APN menu often undoes accidental edits.

Trains and tunnels

High-speed trains between cities such as Rome, Florence and Milan pass through tunnels where any connection can drop. A short loss of data there is normal. Download offline maps and save tickets as screenshots so a gap does not leave you stuck.

Contacting support

If the table and the APN check do not fix it, contact support with your order email, phone model and screenshots of the line and APN settings. Keep the eSIM installed.

Troubleshooting questions

Do I need to set an APN for my Italy eSIM?

Usually not. Travel eSIMs normally set it automatically. Check it only after line selection and roaming.

Why does data stop on Italian trains?

Tunnels and fast-moving trains can interrupt any mobile connection. It usually returns once the train is back in open areas.

Can I use an APN from an Italian carrier?

No. Use only the value from your eSIM instructions or from support.
