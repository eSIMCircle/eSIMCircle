Vietnam eSIM activation guide: QR code or manual entry

Most people scan a QR code and never think about it again. But if you are installing on the same phone that shows the email, or the camera will not read the code, manual entry is the way through.

Published September 21, 2026 · Updated October 9, 2026 · 3 min read

Two ways to add the same eSIM

Your eSIMCircle email contains everything needed to install the Vietnam eSIM in two forms: a QR code, and the same information as text. Use whichever is easier.

Option 1: scan the QR code

This works best when the code is on a second screen, such as a laptop or a printout.

  • iPhone: Settings > Mobile Data > Add eSIM > use the camera to scan.
  • Android: Settings > Network & internet or Connections > SIMs > Add eSIM > scan.

Option 2: enter the details manually

Useful when you only have one phone. The email shows two values:

FieldWhat it is
SM-DP+ addressThe server that delivers your eSIM profile
Activation codeThe code that identifies your specific eSIM

On iPhone, choose Add eSIM, then the option to enter details manually. On Android, look for "Enter code manually" or "Need help?" on the scan screen. Copy each value exactly, including dots and capital letters.

NoteInstall either way on stable Wi-Fi, before you travel. Label the new line "Vietnam".

Activating after landing

At Noi Bai, Tan Son Nhat or Da Nang, open SIM settings, choose the Vietnam line for mobile data and turn on roaming for it. Keep roaming off on your home SIM. Test with a map.

Common snags

The code was already used. Each eSIM installs once. If you scanned it earlier on another phone, contact support instead of trying again.

The phone says the eSIM cannot be added. Check the phone is carrier-unlocked and connected to Wi-Fi, then try again.

Data does not start after landing. Restart, then check the data line and roaming. Do not delete the eSIM.

Troubleshooting questions

Can I install the Vietnam eSIM using only my phone?

Yes. Use manual entry with the SM-DP+ address and activation code from the email instead of scanning the QR code.

Can I scan the same QR code on two phones?

No. Each eSIM installs on one device. Buy one eSIM per phone; several can be bought in one order.

When does the Vietnam eSIM start working?

When you select it for mobile data with roaming on after landing.
