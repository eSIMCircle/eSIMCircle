How to install an eSIM for Malaysia travel when you are setting up several phones

Group and family trips add one extra step: making sure each eSIM ends up on the right phone. A little organisation at home saves a confused huddle in the arrivals hall.

Published August 19, 2026 · Updated October 9, 2026 · 3 min read

One order, several eSIMs

eSIMCircle lets you buy several eSIMs in one purchase. Each one has its own QR code and can be installed on only one phone. Before anyone scans anything, decide which code goes to which person.

Print it or keep it in a shared note. Mark each row as you go.

Installing each phone

Use a laptop or tablet to display the QR codes one at a time, so each phone can scan from a separate screen.

  • iPhone: Settings > Mobile Data > Add eSIM.
  • Android: Settings > Network & internet or Connections > SIMs > Add eSIM.

Name every line "Malaysia". For children's or older relatives' phones, also check that the home SIM stays set for calls and texts so family can still reach them.

NoteA QR code installs once. If someone scans the wrong code, do not delete it; contact support so the codes can be sorted out.

Before the flight

On every phone:

  1. Turn data roaming off on the home SIM.
  2. Turn off automatic data switching.
  3. Save the hotel address offline.

At KLIA

Ask everyone to select the Malaysia line for mobile data and turn on roaming for it. Then do a quick check: each person opens a map. Whoever has no data restarts their phone first. Do this before heading for the train or a ride, so nobody is stuck later.

Sharing data instead

If one phone in the group is older and does not support eSIM, another person can share data by hotspot. Check the hotspot rules on the plan page and size that person's plan up accordingly.

Troubleshooting questions

Can I buy eSIMs for my whole family in one order?

Yes. You can buy several eSIMs in one purchase. Each installs on one phone.

Can one QR code be used on two phones?

No. Each eSIM installs on a single device.

What if a family member's phone does not support eSIM?

Another traveller can share data by hotspot if the plan allows it. Check hotspot rules on the plan page.
