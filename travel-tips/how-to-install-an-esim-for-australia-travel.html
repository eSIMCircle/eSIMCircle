How to install an eSIM for Australia travel

Most trips to Australia start with a very long flight, often with a connection. Installing the eSIM at home means you land in Sydney, Melbourne or Perth with one less job to do.

Published January 22, 2026 · Updated October 8, 2026 · 3 min read

Why install before the flight

Transit airports have Wi-Fi, but you may have little time, a weak connection and a phone battery that has been on for twenty hours. Home Wi-Fi is calmer. Installation only adds the profile; it does not start using data, so there is no downside to doing it early.

What you need

  • An eSIM-compatible phone that is carrier-unlocked.
  • Your eSIMCircle email with the QR code, open on a second screen if possible.
  • Stable Wi-Fi.

Installing on iPhone

  1. Open Settings > Mobile Data > Add eSIM.
  2. Choose to scan a QR code and point the camera at the code in your email.
  3. Follow the prompts and name the line "Australia".
  4. When asked about default lines, keep your home line for calls, texts and data for now.

Installing on Android

  1. Open Settings > Network & internet (Pixel) or Connections > SIM manager (Samsung).
  2. Tap Add eSIM or Add mobile plan and scan the QR code.
  3. Rename the new SIM "Australia".
  4. Leave the home SIM as the data SIM for now.
NoteIf you only have one device, use the manual entry option with the SM-DP+ address and activation code shown in the email.

Planning for where you are going

Australia's cities and main highways have broad coverage, but large parts of the outback have little or none. If your trip includes long drives, download offline maps for the full route and save accommodation details before you set off. That matters more than the size of the plan.

TripData approach
City break in Sydney or MelbourneA fixed-data plan sized to your stay
Road trip with long empty stretchesOffline maps first, then a plan for town stops
Working holiday or long stayLonger validity, and top up or extend as you go

On arrival

Set the Australia eSIM as the mobile data line and turn on data roaming for it. Keep roaming off on your home SIM. If the line shows no service, restart the phone before trying anything else.

Troubleshooting questions

Can I install my Australia eSIM during a layover?

You can, if the airport Wi-Fi is good. Installing at home before you leave is easier and gives you time to contact support if needed.

Will my eSIM work in the outback?

Coverage in remote areas is limited on any network. Download offline maps and save bookings before long drives.

Does installing the eSIM start the plan?

Installing adds the profile. You start using it when you select it for data after landing.
