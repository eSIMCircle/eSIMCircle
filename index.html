Plan styles

Choose by travel behavior, not by label.

A short trip with maps and messages needs a different plan from a work trip with hotspot use. Start with the day that will use the most data.

Daily and FLEX365 plans

Useful when data use changes from day to day or when the itinerary is still flexible.

  • Good for active sightseeing days
  • Helpful for hotspot or remote work sessions
  • Pick the duration that matches the trip

Standard fixed data plans

Useful when you want one clear data bucket for a known travel window.

  • Easy to compare by allowance and validity
  • Good for predictable map and messaging use
  • Top-up may be available on eligible plans

Setup flow

Prepare the phone before the first ride.

Arrival is a bad time to troubleshoot settings. Keep the setup boring and done early.

1

Check compatibility

Confirm the phone supports eSIM and is unlocked for travel data.

2

Install on Wi-Fi

Add the eSIM profile before departure and keep the QR email available.

3

Switch data line

At destination, select the eSIM for mobile data and enable roaming for that line.
